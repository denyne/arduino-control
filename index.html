About NEBULA

Hardware Command Center

VERSION 2.0

NEBULA is a standalone browser-based Arduino dashboard. It uses native HTML, CSS and JavaScript with the Web Serial API. No framework or build tools required. Demo sensor data is generated locally and is not a real hardware measurement.
